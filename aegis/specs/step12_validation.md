## REFERENCE_CASES

A tuple/list of dicts (or dataclasses) with at least:

- `name: str`
- `source: str` — citation string
- `sigma_major`, `sigma_minor`, `miss_x`, `miss_z`, `hard_body_radius`
  (same units within a case)
- `kind`: `"alfano_chan"` or `"pc_max"`

### Required cases (exact numbers)

**Chan-applicable isotropic / near-isotropic** — independent analytic
`aegis.risk.chan.collision_probability` is the referee (Chan 1997 / 2008
when the envelope allows). Alfano Gauss-Chebyshev must agree to
**relative 1e-2** (1%) or absolute 1e-8, whichever is looser.

1. `name="center_small"`  
   sigma_major=1.0, sigma_minor=1.0, miss_x=0.0, miss_z=0.0,
   hard_body_radius=0.01, kind=alfano_chan  
   Citation: `Chan isotropic analytic (same inputs); Alfano 2005 GC`

2. `name="offset_isotropic"`  
   sigma_major=1.0, sigma_minor=1.0, miss_x=1.0, miss_z=0.0,
   hard_body_radius=0.02, kind=alfano_chan

3. `name="anisotropic_chan_ok"`  
   sigma_major=2.0, sigma_minor=1.0, miss_x=0.5, miss_z=0.0,
   hard_body_radius=0.01, kind=alfano_chan  
   Only include in Chan comparison if `chan.is_applicable(...)` is True;
   if not applicable, still run Alfano and compare to
   `collision_probability_simpson` within 5% relative.

4. `name="far_tail"`  
   sigma_major=0.1, sigma_minor=0.1, miss_x=2.0, miss_z=0.0,
   hard_body_radius=0.005, kind=alfano_chan  
   Far-tail; Alfano vs Chan or Simpson. Must be finite and in (0, 1].

**Geometric Pc_max** (Alfano, *Relating Position Uncertainty to Maximum
Conjunction Probability*, JAS 53(2), 2005):

5. `name="pc_max_unit"`  
   hard_body_radius=1.0, miss_distance=10.0 implied via
   `max_collision_probability(1.0, 10.0)`  
   kind=pc_max  
   Published formula: `R^2 / (e * d^2)` = `1 / (e * 100)`.

6. `name="pc_max_zero_miss"`  
   `max_collision_probability(1.0, 0.0) == 1.0`

## evaluate_reference_cases

```
evaluate_reference_cases() -> list[dict]
```

Each result dict:

- `name`, `source`, `alfano_pc` (or `pc_max`), `referee_pc`, `ok` (bool),
  `rel_error`
